One invented English word, defined in a single clear line, for make.fun's
"Invent a Word We Need" bounty.

**thresholdnesia (n.) — walking through a doorway and forgetting why you went there.**

The word names the doorway effect: the everyday moment of crossing a
threshold and losing the reason you went there. English has no everyday
word for it — only the technical term. *Thresholdnesia* is built from
familiar English parts (threshold + amnesia), so it is sayable, spellable
and memorable, and it sounds as though English could have grown it.

## Run it

```sh
python3 main.py
```

The program writes the entry to `/output/entry.txt` (82 characters,
UTF-8). It uses only the Python standard library, touches no network,
and reads nothing outside this repository.
